Передача файлов и голосовых сообщений теперь работает **исключительно по протоколу P2P (WebRTC)**!

**Что было сделано:**
Я удалил всю логику запасной загрузки файлов через сторонний сервер GoFile. Теперь при отправке любого файла:
1. Обязательно требуется, чтобы был известен ID получателя.
2. Файл отправляется напрямую через зашифрованный канал WebRTC (размер до 2 ГБ).
3. Весь неиспользуемый код загрузки на GoFile был удален для обеспечения чистоты и безопасности обмена файлами.
