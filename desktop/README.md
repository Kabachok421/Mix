# Mix для Windows 10/11

Десктопная оболочка (Electron) вокруг веб-клиента Mix. Внутри приложения работает
локальный сервер, который раздаёт клиент и принимает файлы. Вход, чаты и звонки идут через Firebase, как в веб-версии.

## Собрать установщик

Вариант 1. На своём ПК с Windows (нужен Node.js 20+): запустить `build-installer.bat` в корне проекта.
Результат: `desktop\release\Mix-Setup-1.0.0.exe`.

Вариант 2. Без установки чего-либо: любой пуш в ветку `main` запускает GitHub Actions («Release»),
который сам собирает установщик и выкладывает его в Releases репозитория (вкладка Releases справа на главной странице).
Первую установку скачайте оттуда.

## Автообновление

Как это работает:
1. Вы отправляете файлы в `main` (из AI Studio или как угодно).
2. GitHub Actions за 5-10 минут собирает новую версию `1.0.N` (N растёт сам) и создаёт Release.
3. Приложение проверяет Releases через 10 секунд после запуска и затем каждые 30 минут.
4. В правом нижнем углу экрана появляется окно с кнопкой **Download**. По окончании загрузки кнопка меняется на **Restart**.
5. Restart закрывает Mix, ставит обновление и запускает его снова.

Скачиваются только изменившиеся блоки установщика (по `.blockmap`), а не весь файл.
Первое обновление после ручной установки качается целиком, следующие уже частично.

В меню трея есть пункт «Проверить обновления».
Требуется публичный репозиторий `Kabachok421/Mix` и включённые Actions
(Settings → Actions → General → Workflow permissions → Read and write permissions).

## Общий сервер для файлов (важно)

Фото, видео, файлы и голосовые загружаются на сервер (`/api/upload-raw`), а в чат попадает ссылка `/api/files/...`.
В десктопной версии у каждого пользователя свой локальный сервер, поэтому чужой файл он по этой ссылке не получит.

Чтобы файлы доходили до собеседников, разверните `server.ts` в одном месте (VPS, Cloud Run и т. п.)
и впишите его адрес в `desktop/config.default.json` перед сборкой:

    { "apiBase": "https://ваш-сервер.example.com" }

Приложение тогда проксирует все запросы `/api/*` на этот сервер.
Без `apiBase` файлы работают только на том ПК, где отправлены.
Адрес можно поменять и после установки: `%APPDATA%\Mix\config.json` или переменная окружения `MIX_API_BASE`.

## Что умеет

- Установщик NSIS: выбор папки, ярлыки на рабочем столе и в меню «Пуск», деинсталлятор.
- Иконка в трее: закрытие окна сворачивает в трей, выход через меню трея.
- Автозапуск вместе с Windows (пункт в меню трея).
- Системные уведомления, микрофон и камера для звонков и голосовых.
- Один экземпляр приложения, запоминание размера и положения окна.
- Автообновление через GitHub Releases с окном «Download → Restart».

## Разработка

    cd desktop
    npm install
    npm run dev

## Если что-то не работает

Журнал приложения: правый клик по иконке Mix в трее → «Открыть журнал (mix.log)»
(файл `%APPDATA%\Mix\mix.log`). В нём записаны версия, порт и ошибки страницы.

- Вход не сохраняется: вход хранится в адресе `http://localhost:47831`. Если этот порт занят другой программой,
  Mix покажет предупреждение и в журнале будет строка «ЗАПАСНОЙ».
- Статус offline: пока Mix запущен (в том числе в трее), статус остаётся online. При выходе через трей Mix сам ставит offline.
